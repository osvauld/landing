# Osvauld

Osvauld is building Xnet, the extended internet: a private, sovereign and programmable environment for shared software.

A workspace can host chat, threads, interactive documents and custom tools for hundreds of people and their AI. Applications are small Lua programs written on demand over synchronized, JSON-like shared data. Osvauld supplies identity, signed capability permits, encrypted storage, synchronization and the UI runtime.

Each workspace is served by a sovereign node controlled by its community. A node can run on a Raspberry Pi, phone, laptop or server without requiring a traditional domain or static IP.

Important implementation status: `osvauld2` is the current runtime rebuild. Identity, encrypted vaults, workspaces and sandboxed Lua applications are implemented. Peer synchronization, sovereign-node integration and the new permit system are being rebuilt.
